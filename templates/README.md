# Templates

Full-size paper templates for cutting and drilling. Print each one on US Letter paper at
**100 % ("actual size", not "fit to page")**, then check the black-and-white bar on every page
measures **exactly 2 in** with a ruler before you use it. If it doesn't, the printer scaled
the page and every hole would be in the wrong place.

How they are used: trim the paper along the edges marked ✂, line those edges up with the
factory edges of the sheet (protective film still on), tape or glue-stick it down, then prick
each hole centre through the paper with a pin or cut straight through the paper. Two-page
templates overlap on a marked band or match line.

The note "No straightedge lines yet: type the guide offset into the page" on some pages can be
ignored. It refers to an optional extra (lines showing where to clamp a cutting guide) that is
not part of these PDFs.
