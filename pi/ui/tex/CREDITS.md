# Planet pictures (PLANETS tab)

Surface maps wrapped round the 3D globes on the touchscreen's PLANETS tab
(`ui/planets.js`). Resized to 1024 × 512 for the Pi.

| Files | Source | Licence |
|---|---|---|
| sun, mercury, venus, earth, moon (greyscale, tinted per moon), earth_clouds, earth_night, mars, jupiter, saturn, saturn_ring, uranus, neptune | [Solar System Scope](https://www.solarsystemscope.com/textures/) (based on NASA data) | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) — credit shown on screen |
| pluto | NASA / Johns Hopkins APL / SwRI, New Horizons colour map ([Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Pluto_color_mapmosaic.jpg)) | Public domain |

Pluto's far south was never photographed (black on the NASA map); it is filled
with Pluto's average colour so the globe has no hole. Made 26 Sep 2026 with Pillow.
